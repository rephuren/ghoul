# Как помочь проекту

Проект учебный, но замечания и правки приветствуются.

- **Нашли ошибку.** Откройте issue: что запускали, что ожидали, что получили, версия и система. Если это уязвимость, не публикуйте её в issue, см. [SECURITY.md](SECURITY.md).
- **Хотите предложить правку.** Сначала issue с описанием идеи, затем pull request с тестом, который падает без правки и проходит с ней.
- **Перед отправкой** запустите проверки проекта из раздела «Быстрый старт» в [README.md](README.md): тесты и линтеры должны проходить.
- Мелкие правки текста и опечатки можно присылать сразу pull request'ом.
